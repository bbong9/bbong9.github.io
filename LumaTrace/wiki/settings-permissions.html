SETTINGS

设置与权限 按需调整

macOS 设置窗口按常用、功能、管理和系统分组。使用侧栏上的“搜索设置”可直接查找设置项。

设置页面权限说明

设置侧栏

页面按以下顺序排列；输入关键词可查找并打开对应设置。

  • 常用：通用，管理启动、外观和状态。
  • 功能：截图、快速操作、标注、录屏、识别翻译。
  • 管理：历史与存储、快捷键、输入法、鼠标滚动。
  • 系统：权限与诊断、授权与关于。

常用设置

  • 截图：设置截图后的操作、保存位置、文件命名、窗口阴影和长截图。
  • 快速操作：“显示方式”可选默认的“角落卡片”或“顶部挂线”；还可调整卡片大小、自动隐藏和拖拽等行为。
  • 录屏：设置录制格式、声音、鼠标与按键提示和保存位置；“录屏与截图中包含汐痕自己的窗口”默认关闭，仅对本机生效。
  • 识别翻译：在“文字识别”中控制框选识别后自动翻译，在“翻译”中选择语言与服务。系统翻译需要 macOS 15。
  • 历史与存储：管理历史面板、保留规则、隐私和文件占用。

快捷键与输入法

  • “快捷键”分为“全局快捷键”“启动程序”和“截图界面”；“套用推荐方案…”需确认后才会改变现有设置。截图界面功能键只在截图界面内生效。
  • 全局快捷键与 macOS 系统快捷键冲突时，该行的按键区域显示红底，并写明冲突项。可在“系统快捷键冲突”处重新检测，再修改快捷键。
  • 发现新冲突或快捷键注册失败时，菜单栏图标会出现提醒；左键点击提醒可打开快捷键页并定位到相关行。
  • 这里只检测与 macOS 系统快捷键的冲突，不检测第三方软件；即使没有系统冲突，按键仍可能被其他软件占用而没有反应，请自行更换组合。
  • 在“全局快捷键 → 快捷键修改记录”点击“查看记录…”，可查看最近修改的时间、项目、新旧值和来源。记录从 2.25 开始，只记录快捷键配置变化，不记录按键输入。
  • “输入法”中的“未配置应用的行为”可选“保持不变”“切到默认输入法”或“记住上次用的”；已配置规则优先，汐痕自己的窗口不会触发切换。

鼠标滚动

macOS 2.25 起，在“设置 → 鼠标滚动”打开“启用鼠标滚动平滑”，可调整鼠标滚轮的滚动方式；触控板不受影响。此功能需要辅助功能及发送事件权限，缺少权限时可从页面提示前往“权限与诊断”。

  • 平滑：选择“关”“常规”或“高”；档位越高，滚动越柔和、惯性越长。
  • 模拟触控板：仅在“高”平滑时可用，可在 Safari 页面间前进或后退。
  • 反转方向：反转鼠标滚轮的滚动方向。
  • 速度：选择“慢”“中”或“快”，调整每格滚轮滚动的距离。
  • 精准：慢慢滚动滚轮即可精准滚动，无需按修饰键。

请先退出 Mac Mouse Fix，再启用汐痕的鼠标滚动，避免两个软件同时接管滚轮；其他滚轮工具也可能发生冲突。

汐痕的鼠标滚动引擎基于 Mac Mouse Fix，tag 3.1.0，经作者授权用于汐痕，免费、非商用。完整第三方声明可在“设置 → 授权与关于”的关于区域查看。

权限与诊断

  • 截图和手动长截图需要屏幕录制权限；鼠标滚动、自动长截图、窗口内元素识别和历史自动粘贴需要辅助功能权限。
  • 麦克风与系统声音权限按录屏需要开启。保存位置及诊断信息可在“权限与诊断”中检查。
  • 更新后若系统重新询问屏幕录制或辅助功能，请在“系统设置 → 隐私与安全性”重新允许汐痕；列表中可能显示为 LumaTrace。
  • 授权、更新和第三方声明位于“授权与关于”。
